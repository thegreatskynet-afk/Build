# BUILD

A single-page recipe finder for high-protein, low-calorie eating.

- 78 meals and 20 protein desserts, each with macros, an ingredient list, a method and an estimated price
- Profiles for lifters (bulk, cut, recomp and more) and for athletes by sport
- Macro, price and diet filters, plus search by recipe or ingredient
- A daily target calculator, a day builder and a shopping list

## Use it

Open `index.html` in any browser. The whole site is that one file, with no build step. Fonts load from Google Fonts when online.

To host it with GitHub Pages, go to Settings, then Pages, and deploy from the `main` branch root.

## Notes

Macros and prices are estimates. Targets and tips are general starting points, not medical or dietetic advice.
